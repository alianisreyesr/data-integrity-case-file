# Contributing

Thanks for helping improve this portfolio project.

1. Open an issue describing the problem or proposed change.
2. Create a focused branch from `main`.
3. Follow the setup and verification commands in the README.
4. Add tests for workflow, API, security, or AI-boundary changes.
5. Open a pull request explaining the investigation-workflow impact and verification performed.

All cases and evidence must remain fictional. Never contribute confidential investigation details, personal information, employer data, production data, or regulated records. Report vulnerabilities through `SECURITY.md`.
