**ALCOA:** Attributable, Legible, Contemporaneous, Original (or true copy), Accurate  
**ALCOA+ (widely used):** + Complete, Consistent, Enduring, Available (see MHRA / PIC/S)

## Educational mapping in this app

| Attribute | Investigation prompt (examples) |
|-----------|----------------------------------|
| Attributable | Shared accounts? Missing user ID on critical steps? |
| Legible | Unreadable exports? Lost metadata? |
| Contemporaneous | Backdating? Delayed transcription? |
| Original | Overwritten raw files? Uncontrolled copies? |
| Accurate | Calculation errors? Unvalidated spreadsheets? |
| Complete | Deleted failing results? Partial audit trails? |
| Consistent | Conflicting timestamps or versions? |
| Enduring | Retention / backup gaps? |
| Available | Records not retrievable for review? |
